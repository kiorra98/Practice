# Othalart Website

Static website prototype for Othalart Creative Studio.

## Files

- `index.html`: main homepage.
- `styles.css`: visual styles for the homepage.
- `backend.php`: basic PHP POST handler placeholder.
- `script.js`: solitaire prototype script.
- `solitario.html`: standalone solitaire prototype page.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 5177
```

Then visit `http://localhost:5177/index.html`.
